# راهنمای جامع و شفاف متغیرهای محیطی (.env)
## سامانه مدیریت و فروش اشتراک VPN Private

این مستند راهنمای کامل و خط‌به‌خط متغیرهای فایل تنظیمات محیطی (`.env`) است تا بدانید هر متغیر چه نقشی دارد، کدام موارد **اجباری** و کدام **اختیاری** هستند و مقادیر آن‌ها را باید دقیقاً از کجا تهیه کرده و قرار دهید.

---

## ۱. راهنمای گام‌به‌گام راه‌اندازی سریع (Quick Start)

برای اجرای اولیه پروژه در محیط تست یا پروداکشن:
```bash
# ۱. کپی کردن فایل نمونه
cp .env.example .env

# ۲. اجرای کانتینرها با داکر کامپوز
docker compose up -d --build
```

## ۲. جدول جامع متغیرها و نحوه تهیه آن‌ها

### بخش اول: امنیت و هسته سامانه (Core & Security)

| نام متغیر | الزامی / اختیاری | مقدار پیش‌فرض | توضیحات و نحوه دریافت مقدار |
| :--- | :---: | :---: | :--- |
| `PROJECT_NAME` | اختیاری | `"VPN Private"` | عنوان نمایشی سامانه شما. |
| `ENVIRONMENT` | اختیاری | `production` | محیط اجرا (`production` یا `development`). |
| `DEBUG` | اختیاری | `false` | حالت لاگ خطاها (`false` برای امنیت در محیط واقعی). |
| `SECRET_KEY` | **الزامی** | رشته ۶۴ کاراکتری | کلید اختصاصی رمزنگاری سشن‌ها و توکن‌های ورود JWT. <br>📌 **نحوه تولید:** دستور زیر را در ترمینال لینوکس یا پایتون اجرا کنید:<br>`python -c "import secrets; print(secrets.token_hex(32))"` |
| `ENCRYPTION_KEY` | **الزامی** | کلید Base64 Fernet | کلید رمزنگاری متقارن برای ذخیره امن پسوردهای پنل ۳X-UI در دیتابیس.<br>📌 **نحوه تولید:** دستور زیر را اجرا کنید:<br>`python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"` |
| `ADMIN_WEB_USERNAME` | اختیاری | `admin` | نام کاربری ورود به پنل تحت وب مدیریت. |
| `ADMIN_WEB_PASSWORD` | اختیاری | `admin` | رمز عبور ورود به پنل تحت وب مدیریت. |
| `ADMIN_2FA_ENABLED` | اختیاری | `false` | وضعیت ورود دو مرحله‌ای پیش‌فرض (`false` خاموش، `true` روشن). می‌توانید بعداً دستی از پنل روشنش کنید. |
| `ADMIN_TOTP_SECRET` | اختیاری | (خالی) | کلید اختصاصی Google Authenticator که با زدن دکمه پیکربندی در پنل خودکار ساخته می‌شود. |

### بخش دوم: ربات تلگرام (Telegram Bot)

| نام متغیر | الزامی / اختیاری | نحوه دریافت و کاربرد |
| :--- | :---: | :--- |
| `BOT_TOKEN` | **الزامی** | توکن ربات تلگرام شما.<br>📌 **نحوه دریافت:** وارد تلگرام شده و به ربات رسمی **[@BotFather](https://t.me/BotFather)** پیام دهید. با دستور `/newbot` ربات جدید بسازید و توکن دریافت شده (شبیه `123456789:ABC...`) را اینجا بگذارید.<br>💡 *نکته:* بعداً از طریق پنل وب نیز می‌توانید ربات را تغییر دهید یا بات‌های جدید اضافه کنید. |
| `BOT_USERNAME` | اختیاری | یوزرنیم ربات تلگرام شما بدون علامت @ (مثال: `MyVpnBot`). برای ساخت لینک‌های هوشمند اشتراک و QR کد کارت‌های چاپی استفاده می‌شود. |
| `ADMIN_TELEGRAM_IDS` | **الزامی** | شناسه عددی (عددی و یونیک) ادمین‌های ربات. برای چند ادمین با کاما جدا کنید (مثال: `123456789,987654321`).<br>📌 **نحوه دریافت:** به ربات **[@userinfobot](https://t.me/userinfobot)** در تلگرام پیام دهید تا عددی به عنوان `Id` به شما بدهد. |
| `CHANNEL_USERNAME` | اختیاری | آیدی کانال تلگرام شما جهت قفل عضویت اجباری (مثال: `my_vpn_channel`). |
| `SUPPORT_USERNAME` | اختیاری | آیدی تلگرام پشتیبان جهت نمایش به کاربران (مثال: `my_support`). |

### بخش سوم: پایگاه داده (Database)

این سامانه به صورت پیش‌فرض از دیتابیس سبک و فوق‌العاده سریع **SQLite** پشتیبانی می‌کند و نیازی به نصب دیتابیس جانبی ندارد. در عین حال از **PostgreSQL** نیز به صورت کامل پشتیبانی می‌نماید.

* **حالت پیش‌فرض (SQLite - بدون نیاز به دستکاری):**
  ```env
  DATABASE_URL=sqlite+aiosqlite:///vpn_private.db
  DATABASE_URL_SYNC=sqlite:///vpn_private.db
  ```
* **حالت PostgreSQL (در صورت تمایل به دیتابیس سروری سنگین):**
  ```env
  DATABASE_URL=postgresql+asyncpg://vpn_user:password@localhost:5432/vpn_private
  DATABASE_URL_SYNC=postgresql://vpn_user:password@localhost:5432/vpn_private
  ```

### بخش چهارم: روش‌های پرداخت (Payment Methods)

#### ۱. کارت به کارت شتابی (ریالی)
| نام متغیر | پیش‌فرض | توضیحات |
| :--- | :---: | :--- |
| `CARD_TO_CARD_ENABLED` | `true` | روشن یا خاموش بودن امکان پرداخت کارت به کارت در ربات. |
| `CARD_NUMBER` | `6037997100000000` | شماره کارت پیش‌فرض ۱۶ رقمی بانکی. |
| `CARD_HOLDER` | `نام دارنده` | نام و نام خانوادگی صاحب کارت. |
| `CARD_BANK_NAME` | `بانک ملی` | نام بانک صادرکننده کارت. |
| `CARD_IBAN` | `IR...` | شماره شبا اختیاری. |
*💡 نکته مهم:* سامانه مجهز به سیستم **چند کارته (Multi-Card)** است؛ بنابراین پس از بالا آمدن پنل می‌توانید بی‌نهایت کارت دیگر با بانک‌های مختلف اضافه کرده و آن‌ها را روشن/خاموش کنید.

#### ۲. ارز دیجیتال تتر (Crypto USDT - شبکه‌های TRC20 و BEP20)
| نام متغیر | پیش‌فرض | توضیحات |
| :--- | :---: | :--- |
| `CRYPTO_ENABLED` | `false` | روشن/خاموش بودن درگاه پرداخت کریپتو. |
| `CRYPTO_TRC20_ENABLED`| `true` | فعال بودن تتر روی شبکه ترون (TRC-20). |
| `CRYPTO_WALLET_TRC20` | `T...` | آدرس کیف پول تتر ترون شما که با حرف `T` آغاز می‌شود (از تراست‌ولت، نوبیتکس و...). |
| `CRYPTO_BEP20_ENABLED`| `false` | فعال بودن تتر روی شبکه بایننس اسمارت چین (BEP-20). |
| `CRYPTO_WALLET_BEP20` | `0x...` | آدرس کیف پول تتر BSC شما که با `0x` آغاز می‌شود. |
| `USDT_TOMAN_RATE` | `70000` | نرخ محاسبه هر تتر به تومان در ربات تلگرام. |

#### ۳. درگاه آنلاین شاپرک (زرین‌پال / ZarinPal)
| نام متغیر | پیش‌فرض | توضیحات |
| :--- | :---: | :--- |
| `ZARINPAL_MERCHANT_ID` | `00000000-...` | کد مرچنت ۳۶ کاراکتری دریافتی از پنل زرین‌پال. |
| `ZARINPAL_SANDBOX` | `false` | حالت تست تستی زرین‌پال (`false` برای درگاه واقعی). |

### بخش پنجم: قوانین تجاری، کیف پول و اکانت تست (Business Rules)

| نام متغیر | پیش‌فرض | توضیحات |
| :--- | :---: | :--- |
| `MIN_WALLET_TOPUP_TOMAN` | `10000` | حداقل مبلغ شارژ کیف پول توسط کاربر به تومان. |
| `REFERRAL_COMMISSION_PERCENT` | `10` | درصد پورسانت معرف از خرید زیرمجموعه در سیستم رفرال (مثلاً ۱۰ یعنی ۱۰٪). |
| `TRIAL_ENABLED` | `true` | روشن یا خاموش بودن اکانت تست رایگان برای کاربران جدید. |
| `TRIAL_TRAFFIC_MB` | `1024` | حجم اکانت تست رایگان به مگابایت (۱۰۲۴ مگابایت = ۱ گیگابایت). |
| `TRIAL_DURATION_HOURS` | `24` | مدت زمان اعتبار اکانت تست به ساعت. |

## ۳. خلاصه متغیرهای ضروری که کاربر حتماً باید تغییر دهد

اگر برای اولین بار پروژه را راه‌اندازی می‌کنید، تنها این **۴ مورد** را کافیست پر کنید و بقیه روی مقادیر استاندارد کار می‌کنند:
1. `SECRET_KEY` (تولید با دستور پایتون)
2. `ENCRYPTION_KEY` (تولید با دستور پایتون)
3. `BOT_TOKEN` (از BotFather تلگرام)
4. `ADMIN_TELEGRAM_IDS` (شناسه عددی تلگرام شما)
