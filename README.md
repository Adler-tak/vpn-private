## 🌟 معرفی پروژه

پلتفرم **VPN Private** یک سامانه جامع، مدرن و مقیاس‌پذیر برای اتوماسیون کامل فروش، مدیریت کاربران، حسابداری مالی و مانیتورینگ سرویس‌های VPN است. این سامانه به طور مستقیم با چندین کنترل‌پنل مستقل **3x-ui نسخه v3.11** ادغام شده و تمامی فرآیندها اعم از ثبت سفارش، دریافت فیش کارت‌به‌کارت یا پرداخت اینترنتی، صدور آنی اکانت در پروتکل‌های **VLESS (Reality), VMess, Trojan** و تحویل QR Code و لینک هوشمند سابسکرایب را به صورت کاملاً خودکار انجام می‌دهد.

همچنین دارای **پنل وب اختصاصی مدیریت (Web Admin Panel)** به همراه احراز هویت دو مرحله‌ای تلگرامی (2FA OTP) می‌باشد.

## ⚡ ویژگی‌های کلیدی

- 🌐 **پشتیبانی از چندین پنل 3x-ui همزمان:** اتصال به سرورهای مختلف در کشورهای گوناگون با رمزنگاری متقارن Fernet برای حفظ پسورد پنل‌ها.
- 🤖 **ربات تلگرام هوشمند (Aiogram 3):** رابط کاربری کاملاً فارسی و روان، کیبوردهای شیشه‌ای، منوی خرید چندمرحله‌ای، تمدید اشتراک، دریافت کانفیگ و استعلام حجم لحظه‌ای.
- 🖥 **پنل تحت وب مدیریت (FastAPI + Bootstrap):** داشبورد آماری، مدیریت پلن‌ها، مانیتورینگ تراکنش‌ها، کاربران و نودها با تایید دو مرحله‌ای (2FA OTP) در تلگرام.
- 💳 **سیستم مالی و حسابداری دوبل (Double-Entry Ledger):** تراز دائمی دارایی‌ها، بدهی‌ها، درآمد و هزینه‌ها همراه با کیف پول داخلی قابل شارژ.
- 🧾 **پشتیبانی از روش‌های پرداخت متنوع:** پرداخت دستی کارت‌به‌کارت (با ارسال فیش و تایید ادمین) و درگاه آنلاین زرین‌پال.
- ⏰ **همگام‌سازی خودکار ترافیک و انقضا:** بررسی دوره‌ای مصرف، غیرفعال‌سازی خودکار در پنل در صورت پایان حجم یا تاریخ، و ارسال هشدارهای مصرف به کاربر.

## 🛠 پیش‌نیازها

برای استقرار و راه‌اندازی این سیستم به موارد زیر نیاز دارید:
1. **سرور لینوکس (VPS):** ترجیحاً اوبونتو 22.04 یا 24.04 (حداقل 1 هسته CPU و 2 گیگابایت رم).
2. **داکر و داکر کامپوز:** Docker Engine و Docker Compose v2.
3. **توکن ربات تلگرام:** دریافتی از [@BotFather](https://t.me/BotFather).
4. **شناسه عددی تلگرام ادمین‌ها:** با ارسال پیام به [@userinfobot](https://t.me/userinfobot) در تلگرام شناسه عددی (Id) خود را بردارید.
5. **پنل 3x-ui:** حداقل یک سرور که پنل 3x-ui v3.11 روی آن فعال باشد.

## 🚀 نصب خودکار با ۱ دستور (روش پیشنهادی و سریع)

سریع‌ترین و بی‌دردسرترین روش استقرار VPN Private روی سرور لینوکس (Ubuntu 20.04/22.04/24.04 یا Debian 11/12) اجرای اسکریپت نصب هوشمند تک‌خطی زیر در ترمینال سرور است:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/Adler-tak/vpn-private/main/install.sh)
```

### عملکرد اسکریپت نصب هوشمند:
1. **بررسی پیش‌نیازها و سیستم‌عامل:** اعتبارسنجی کاربر ریشه (Root) و توزیع لینوکس.
2. **نصب پکیج‌های پایه:** نصب خودکار `curl`, `git`, `openssl`, `jq`, `ufw`, `python3`, `sqlite3` و وابستگی‌ها.
3. **نصب داکر و داکر کامپوز:** در صورت عدم وجود، نسخه رسمی Docker Engine و Compose به صورت خودکار نصب و فعال می‌شود.
4. **کلون مخزن:** سورس پروژه در مسیر استاندارد `/opt/vpn-private` قرار می‌گیرد.
5. **ویزارد پیکربندی تعاملی:**
   * دریافت و اعتبارسنجی توکن ربات تلگرام
   * دریافت شناسه عددی ادمین
   * دریافت نام کاربری ربات
   * تنظیم نام کاربری و رمز عبور پنل وب ادمین
   * تولید خودکار کلیدهای امنیتی فوق امن `SECRET_KEY` و Fernet `ENCRYPTION_KEY`
   * تولید هش امن Bcrypt و نوشتن امن فایل `.env` با دسترسی `chmod 600`.
6. **پیکربندی شبکه داکر:** ساخت خودکار شبکه `nginx-proxy-manager_default` برای پیشگیری از هرگونه خطای شبکه.
7. **بیلد و اجرای کانتینرها:** کامپایل و اجرای ایزوله سرویس‌های وب FastAPI و ربات تلگرام.
8. **اجرای Seed Data:** ساخت جداول دیتابیس، سرفصل‌های دوبل حسابداری، سرورهای نمونه و پلن‌های پیش‌فرض.
9. **نصب ابزار سراسری CLI:** ایجاد دستور سراسری `vpn-private` در مسیر `/usr/local/bin/vpn-private`.
10. **چاپ بنر دسترسی:** نمایش خلاصه اطلاعات ورود به پنل، آدرس آی‌پی، و وضعیت ربات.

## 🐳 راهنمای راه‌اندازی دستی با داکر

### گام اول: کلون کردن مخزن
وارد سرور خود شوید و کد پروژه را دریافت کنید:
```bash
git clone https://github.com/Adler-tak/vpn-private.git /opt/vpn-private
cd /opt/vpn-private
```

---

### گام دوم: ساخت و تنظیم فایل `.env`
ابتدا یک نسخه از فایل نمونه بسازید:
```bash
cp .env.example .env
nano .env
```

سپس مقادیر مهم زیر را در `.env` پر کنید:

#### ۱. تولید کلیدهای امنیتی (SECRET_KEY و ENCRYPTION_KEY):
دستورات زیر را در ترمینال اجرا کنید و خروجی آن‌ها را داخل `.env` قرار دهید:
```bash
# تولید SECRET_KEY
python3 -c "import secrets; print(secrets.token_hex(32))"

# تولید ENCRYPTION_KEY (کلید Fernet 32 بایتی)
python3 -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

#### ۲. تولید هش رمز عبور پنل وب ادمین (`ADMIN_WEB_PASSWORD_HASH`):
برای رمز دلخواه خود برای ورود به پنل وب، هش bcrypt بسازید:
```bash
python3 -c "import bcrypt; print(bcrypt.hashpw(b'رمز_دلخواه_شما', bcrypt.gensalt()).decode())"
```
مقدار خروجی را در متغیر `ADMIN_WEB_PASSWORD_HASH` قرار دهید.

#### ۳. پر کردن متغیرهای اصلی:
* `BOT_TOKEN`: توکن دریافتی از @BotFather
* `ADMIN_TELEGRAM_IDS`: شناسه‌های عددی ادمین‌ها (جدا شده با کاما، مثلاً `123456789,987654321`)
* `BOT_USERNAME`: نام کاربری ربات بدون @
* `ADMIN_WEB_USERNAME`: نام کاربری ورود به پنل وب (مثلاً `admin`)
* `CARD_NUMBER` و `CARD_HOLDER`: اطلاعات کارت بانکی برای پرداخت کارت‌به‌کارت
* `DATABASE_URL`: برای حالت لوکال و داکر به صورت پیش‌فرض روی SQLite تنظیم شده است:
  ```env
  DATABASE_URL=sqlite+aiosqlite:///vpn_private.db
  DATABASE_URL_SYNC=sqlite:///vpn_private.db
  ```

---

### گام سوم: دریافت ایمیج رسمی و اجرای کانتینرها
کانتینرها از ایمیج رسمی و از پیش ساخته شده روی داکر هاب (`adprivate/vpn-private:latest`) استفاده می‌کنند و در چند ثانیه بدون نیاز به کامپایل راه‌اندازی می‌شوند:

```bash
docker compose pull
docker compose up -d
```

> 💡 **نکته برای توسعه‌دهندگان:** در صورتی که کدهای پایتون را مستقیماً تغییر داده‌اید و می‌خواهید ایمیج لوکال جدیدی بسازید، از دستور `docker compose up -d --build` استفاده کنید.

برای بررسی اجرای صحیح کانتینرها:
```bash
docker compose ps
```

## 🖥 راهنمای پنل وب مدیریت (Web Admin Panel)

سامانه دارای پنل مدیریت تحت وب واکنش‌گرا و قدرتمند است:

1. **آدرس پنل:**
   ```text
   http://SERVER_IP:8000/admin
   ```
2. **ورود به پنل:**
   * **نام کاربری:** مطابق مقدار `ADMIN_WEB_USERNAME` در `.env`
   * **رمز عبور:** رمز متناظر با هش `ADMIN_WEB_PASSWORD_HASH`
3. **تأیید هویت دو مرحله‌ای (2FA OTP):**
   * بلافاصله پس از ورود نام کاربری و رمز، یک کد یک‌بار مصرف ۶ رقمی توسط ربات تلگرام به آیدی ادمین ارسال می‌شود.
   * با وارد کردن این کد، وارد داشبورد مدیریتی خواهید شد.
4. **امکانات داشبورد وب:**
   * مشاهده نمودار درآمد، آمار کاربران و ترافیک کل
   * مدیریت پلن‌ها و محصولات ترافیکی
   * بررسی و تایید فیش‌های کارت‌به‌کارت
   * مانیتورینگ سلامت سرورها و پنل‌های 3x-ui

## 📡 نحوه اتصال پنل‌های 3x-ui و تعریف سرور

شما می‌توانید هم از طریق **پنل وب** و هم از طریق **ربات تلگرام** پنل‌های ۳X-UI خود را متصل فرمایید:

### از طریق پنل وب مدیریت (پیشنهادی):
1. در پنل وب به تب **«سرورها و نودها»** بروید.
2. روی دکمه **«+ افزودن پنل جدید»** کلیک کنید.
3. مشخصات پنل را وارد نمایید:
   * **نام نمایشی پنل** (مثال: `پنل آلمان ۱`)
   * **آدرس URL:** همراه با پورت (مثال: `http://1.2.3.4:2053` یا با دامنه)
   * **مسیر وب (Path):** مسیر ساب‌پت (در صورت عدم استفاده، `/`)
   * **نام کاربری و کلمه عبور ادمین پنل**
   * **کد ورود دو مرحله‌ای (TOTP Secret):** در صورت فعال بودن ۲FA در پنل
4. سیستم به طور خودکار به پنل متصل شده، اینباندها (Inbounds) را کشف کرده و سرور را آماده صدور اکانت می‌کند.

### از طریق ربات تلگرام:
1. در پیوی ربات، دستور `/admin` را ارسال کنید.
2. از منوی مدیریت، روی **«🖥 مدیریت پنل‌ها و سرورها»** کلیک کنید.
3. دکمه **«➕ افزودن پنل جدید»** را بزنید و اطلاعات درخواستی را به ترتیب ارسال فرمایید.

## 💳 سیستم درگاه‌های پرداخت چندگانه (Multi-Gateway)

پلتفرم به یک موتور پرداخت ماژولار و بسیار منعطف مجهز است که از تب **«مدیریت درگاه‌ها و روش‌های پرداخت»** در پنل وب قابل پیکربندی است:

1. **درگاه پرداخت الکترونیک سامان (SEP - شاپرک):**
   * پشتیبانی از پرداخت آنلاین بانکی تحت سوییچ شاپرک با تر ترمینال و مرچنت آی‌دی.
   * امکان تعریف چندین درگاه سامان به صورت همزمان.
2. **درگاه پرداخت واسط آیدی پی (IDPay):**
   * اتصال از طریق وب‌سرویس API با قابلیت سوئیچ حالت تستی (Sandbox) و محیط اصلی (Production).
3. **درگاه زرین‌پال (ZarinPal):**
   * پشتیبانی از مرچنت‌های متعدد زرین‌پال با اعتبارسنجی خودکار تراکنش‌ها.
4. **سیستم چند کارتی هوشمند کارت به کارت (Multi-Card Shitab):**
   * امکان تعریف بی‌نهایت کارت بانکی با شماره کارت، نام صاحب حساب، نام بانک و شماره شبا.
   * چرخش هوشمند و نوبتی بین کارت‌های فعال جهت توزیع تراکنش‌ها و جلوگیری از مسدودیت بانکی.
5. **درگاه ارز دیجیتال تتر (USDT Multi-Network):**
   * پشتیبانی از شبکه‌های **TRC-20 (Tron)**، **BEP-20 (BSC)** و **TON**.
   * تعیین نرخ برابری تتر به تومان و ثبت خودکار فیش و کیف پول.

## 🎟 سیستم کارت‌های ووچر و هدیه (Vouchers)

سامانه مجهز به سیستم مدیریت کامل کدهای ووچر (کارت اسکرچ / کد شارژ اشتراک) است:

1. **ایمپورت کدهای ووچر اکسل (مهاجرت از سیستم‌های قدیمی):**
   * پشتیبانی از فرمت ۳ ستونه ساده:
     * **ستون ۱:** مدت زمان بر حسب ماه (محاسبه دقیق ۳۶۵ روز برای پلن‌های ۱ ساله)
     * **ستون ۲:** نام‌کاربری (Username)
     * **ستون ۳:** کلمه عبور (Password)
   * تخصیص خودکار به پلن‌های سیستم و ثبت در پایگاه‌داده.
2. **جداسازی و خروجی اکسل:**
   * امکان فیلتر ووچرهای استفاده‌شده و استفاده‌نشده با یک کلیک.
   * دکمه خروجی اکسل از کدهای مصرف‌نشده جهت فروش در کانال‌ها یا توزیع فیزیکی.
3. **تولید و چاپ کارت ووچر:**
   * امکان تولید تکی یا گروهی کدهای رندوم، قابل استفاده در ربات برای خرید ۱ کلیکه بدون کارت به کارت.

## 🛡 تنظیمات پروکسی و اتصال ربات تلگرام

جهت اتصال بدون قطعی ربات تلگرام بر روی سرورهای داخل کشور یا مناطق با فیلترینگ شدید:
* از تب **«مدیریت ربات تلگرام»** در پنل ادمین، سوییچ **پروکسی اختصاصی ربات** را فعال فرمایید.
* پشتیبانی کامل از پروتکل‌های **SOCKS5** و **HTTP** (با یا بدون یوزرنیم و پسورد):
  ```text
  socks5://127.0.0.1:1080
  socks5://username:password@192.168.1.1:1080
  http://127.0.0.1:8080
  ```
* تست زنده اتصال با فشردن دکمه **«تست اتصال به تلگرام»**.
