اتصال پنل جدید به سامانه (3X-UI / VPN-UI)

پروتکل (http/https)، دامنه و پورت پنل را وارد نمایید.

با وارد کردن API Token پنل ۳X-UI، حتی در صورت فعال‌سازی تایید دو مرحله‌ای (Google Authenticator 2FA) روی پنل، اتصال سیستم همواره برقرار می‌ماند. با وارد کردن توکن، نیازی به نام کاربری و پسورد نیست.

هنگام ثبت، سامانه لاگین زنده و اینباندهای پنل را فوراً دریافت و هماهنگ می‌کند. رمز عبور به‌صورت انکریپت‌شده در پایگاه داده امن ذخیره می‌شود.
